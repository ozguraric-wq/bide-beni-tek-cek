# Bi’de Beni Tek Çek

Eskişehir’in 14 ilçesini insan, mekân ve hafıza üzerinden anlatan belgesel dizi projesi için hazırlanmış korumalı proje sunum sitesi.

## Geliştirme

```bash
npm ci
npm run dev
```

## Statik çıktı

```bash
npm run build
```

GitHub Pages iş akışı, depo adını otomatik olarak temel yol kabul eder ve `main` dalına yapılan gönderimlerde siteyi yayımlar. Depo ayarlarında **Settings → Pages → Source** alanı **GitHub Actions** olarak seçilmelidir.

Demo erişim bilgileri kaynak dosyalarında açık metin olarak tutulmaz; proje paydaşlarıyla ayrıca paylaşılır.
